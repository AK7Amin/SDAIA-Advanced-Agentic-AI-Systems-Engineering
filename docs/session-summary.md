## ما راجعه النقاد وأُصلح

**الجولة 1 (قبل التنفيذ — 3 وكلاء متوازيين)**: دلالات `interrupt()` (فصل
escalate/human_gate)، fixtures مفقودة، تسريب PII للcheckpoint، سطح اختراق ضيق،
دليل «قبل/بعد» غير مخطط، تكلفة لكل وثيقة غير مُنفّذة. التفصيل:
`docs/critique-round-1.md`.

**الجولة 2 (بعد التنفيذ — رخيص/غالٍ)**: فحوص ميكانيكية (haiku) + مراجعة
معمارية/أمنية عميقة (Fable). أُصلح: تسرب `.env` لصورة Docker، `BudgetGuard`
غير موصول، تناقض دليل الاستئناف، مسار الخطاب بلا إثبات، ادعاءات زائدة.

## ما بقي مفتوحًا (قرارات لك)

1. **الrubric الحقيقي لم يصل** — البناء على rubric مستنتج
   (`docs/rubric-predicted.md`). عند وصول ملف المهندس: قارن البنود وأعد
   التوزين؛ البنية تسمح بذلك بلا إعادة بناء.
2. **حافة re-plan على UNCERTAIN** غير منفذة (UNCERTAIN يُصعَّد بشريًا — أكثر
   تحفظًا). مسجّلة كترقية لا كادعاء.
3. **صائغ الإشعار Jinja2** غير منفذ (عقدة notify تسجّل الحالة فقط) — وُثّق بصدق.
4. **MinIO/Postgres/Grafana** خارج النطاق عمدًا، مذكورة في README كترقيات.
5. **الفريق**: اتفقتم أن كل واحد يبني فكرته — هذا مشروعك أنت (الفكرة الرابعة
   المدموجة). المهندس يسمح بأي فكرة تحقق شروط ملف التقييم.

## قبل العرض

اتبع `demo.md`: سخّن مضمِّن ChromaDB، افحص رصيد مفتاحي OpenRouter (النموذج
المجاني له حد يومي)، وشغّل `python main.py run` مرة لتوليد أدلة حديثة.
